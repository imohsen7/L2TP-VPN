# L2TP VPN Client Android 7+ (API 24+) Project

پروژه کامل اپلیکیشن اندروید برای اتصال به L2TP/IPSec VPN با پشتیبانی از حداقل اندروید ۷٫۰ (API 24) تا اندروید ۱۵.
ظاهر برنامه دقیقا ۱۰۰٪ منطبق بر پیش‌نمایش وب (تم تاریک مدرن، دکمه لمسی دایره‌ای، مانیتورینگ زنده سرعت آپلود/دانلود و حجم ترافیک، زبان فارسی) پیاده‌سازی شده و از طریق پل بومی Android WebView با سرویس VpnService ارتباط برقرار می‌کند.

## روش‌های ساخت فایل APK نهایی:

### روش ۱: ساخت خودکار APK با GitHub Actions (رایگان و بدون نیاز به کامپیوتر یا اندروید استودیو)
۱. محتویات این فایل ZIP را در یک ریپازیتوری جدید در گیت‌هاب (GitHub) آپلود و Commit کنید.
۲. به تب **Actions** در بالای ریپازیتوری بروید.
۳. گردش کار **Build Android APK** را مشاهده می‌کنید که به صورت خودکار اجرا می‌شود (یا دکمه Run workflow را بزنید).
۴. پس از اتمام ساخت (حدود ۱ الی ۲ دقیقه)، فایل **L2TP-VPN-Android-Debug-APK** در بخش **Artifacts** در پایین صفحه اکشن برای دانلود مستقیم آماده است!

### روش ۲: کامپایل با Android Studio
۱. برنامه **Android Studio** را باز کنید.
۲. گزینه **Open** را انتخاب کرده و این پوشه پروژه را انتخاب نمایید.
۳. اجازه دهید پروژه Sync شود و سپس از منوی بالا روی **Build > Build Bundle(s) / APK(s) > Build APK(s)** کلیک کنید.
۴. فایل APK در مسیر `app/build/outputs/apk/debug/app-debug.apk` تولید می‌شود.

### مشخصات فنی:
- حداقل نسخه اندروید: Android 7.0 Nougat (minSdk 24)
- سازگار با جدیدترین نسخه‌ها: Android 8, 9, 10, 11, 12, 13, 14, 15
- بدون صفحه سفید: کدهای UI به صورت محلی و کامپایل‌شده (Offline-First) داخل `assets/www` قرار دارند.
- کرش‌نکردن سرویس: رفع کامل مشکل Notification و دسترسی FGS در سرویس VpnService.
