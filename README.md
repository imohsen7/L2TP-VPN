# L2TP VPN Client Android 7+ (API 24+) Project

پروژه کامل اپلیکیشن اندروید برای اتصال به L2TP/IPSec VPN با پشتیبانی از حداقل اندروید ۷٫۰ (API 24) و تمامی نسخه‌های بالاتر.
ظاهر برنامه دقیقا ۱۰۰٪ منطبق بر پیش‌نمایش وب (تم تاریک مدرن، دکمه لمسی دایره‌ای، نمودار زنده ترافیک، زبان فارسی) پیاده‌سازی شده و از طریق پل بومی Android WebView با سرویس VpnService ارتباط برقرار می‌کند.

## روش‌های ساخت فایل APK نهایی:

### روش ۱: ساخت خودکار APK با GitHub Actions (رایگان و بدون نیاز به کامپیوتر یا اندروید استودیو)
1. محتویات این فایل ZIP را در یک ریپازیتوری جدید در گیت‌هاب (GitHub) آپلود و Commit کنید.
2. به تب **Actions** در بالای ریپازیتوری بروید.
3. گردش کار **Build Android APK** را مشاهده می‌کنید که به صورت خودکار اجرا می‌شود (یا دکمه Run workflow را بزنید).
4. پس از اتمام ساخت، فایل **L2TP-VPN-Android-Debug-APK** در بخش **Artifacts** در پایین صفحه اکشن برای دانلود مستقیم آماده است!

### روش ۲: کامپایل با Android Studio
1. برنامه **Android Studio** را باز کنید.
2. گزینه **Open** را انتخاب کرده و این پوشه پروژه را انتخاب نمایید.
3. اجازه دهید پروژه Sync شود و سپس از منوی بالا روی **Build > Build Bundle(s) / APK(s) > Build APK(s)** کلیک کنید.
4. فایل APK در مسیر `app/build/outputs/apk/debug/app-debug.apk` تولید می‌شود.
